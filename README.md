## 🎯 Who Is This For?

- **DevOps Engineers** looking to master Kubernetes
- **Developers** who want to understand container orchestration
- **Students** preparing for **CKA / CKAD / CKS** certifications
- **SREs** who manage production Kubernetes clusters

## 🛠️ Prerequisites

- Basic Linux command-line knowledge
- Understanding of containers (Docker)
- Familiarity with YAML syntax
- Networking fundamentals (TCP/IP, DNS, HTTP)

## 📖 How to Use These Notes

1. **Beginners** → Start from Module 01 and progress sequentially
2. **Intermediate** → Jump to Modules 05–10 for workload & networking
3. **Advanced** → Modules 11–18 cover security, Helm, CI/CD, and production ops
4. **Exam Prep** → Module 18 has dedicated CKA/CKAD cheat sheets and practice
